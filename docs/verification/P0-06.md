## Đã làm

- SmallRye JWT kiểm signature bằng JWKS, thuật toán được cấu hình (ES256), issuer/audience/expiry/skew và required claims. Subject UUID và role Auth authenticated; không lấy user ID từ body/header.
- GET/POST `/api/v1/me/profile`: owner read/bootstrap trong transaction; chống trùng subject/username, 409 khi username đã dùng. Bootstrap mặc định MEMBER qua trigger tin cậy, không đọc metadata để cấp quyền.
- Public profile theo username/ID chỉ chứa dữ liệu công khai của ACTIVE; birth date/phone/role chỉ xuất hiện ở me.
- `/api/v1/admin/access` dùng role database; hạ quyền/khóa tài khoản tác động ngay với token còn hạn. Runtime không sửa role/status.
- Validation và từ chối thuộc tính lạ như role/id; chuẩn hóa JSON lỗi 400/401/403 cùng request ID, WWW-Authenticate. Sửa trường hợp framework mặc định trả challenge 401 rỗng.
- OpenAPI v1.1 thêm owner/bootstrap/admin/by-ID; không tạo API cập nhật hồ sơ P2 trước phạm vi.
- JWKS test ES256 tạo trong bộ nhớ, chữ ký được xác minh thật; không lưu private key hoặc access token vào repo, không mock bỏ qua xác thực.
