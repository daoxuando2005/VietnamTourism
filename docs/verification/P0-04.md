## Đã thực hiện

1. Tạo service Java 21/Quarkus 3.40.1.2 LTS với Maven Wrapper/Enforcer/BOM/plugin khóa version. Build từ thư mục service không phụ thuộc root Maven project hoặc service khác.
2. Tách `ProfileResource`, response/error DTO, `ProfileApplicationService`, domain `PublicProfile`, repository interface và JPA implementation/entity. Không trả persistence entity qua API hoặc chia sẻ DB/entity giữa service.
3. GET `/api/v1/profiles/{username}` kiểm username trước truy vấn, chỉ chọn hồ sơ ACTIVE, ánh xạ DTO chỉ gồm trường công khai; missing/hidden dùng 404, dependency chưa cấu hình dùng 503. Không có dữ liệu mẫu hoặc repository trả profile giả trong runtime.
4. PERSISTENCE mặc định tắt; inject EntityManager qua `Instance` để service vẫn khởi động, liveness UP nhưng readiness DOWN. Không tự sửa schema, Flyway không migrate-at-start. Folder migration ghi rõ schema/role P0-05 chưa triển khai.
5. Error envelope theo hợp đồng, header/cache no-store, request ID có giới hạn định dạng. Log method/status/request ID, không Authorization/body. Acquisition/statement/transaction timeout; giới hạn body/HTTP read/idle.
6. Gateway Nginx riêng, chỉ route public profile và health; không mở `/q/*`/API riêng tư. Edge tạo ID mới, chuyển vào service, loại header tự khai user ID/role, chuyển Authorization đúng boundary. Connect 2s/read-send 5s, không retry, rate limit 20 r/s burst 40, body 1 MiB và JSON lỗi.
7. Dockerfile multi-stage cho service, runtime JRE đủ `quarkus-app`, user 10001; gateway unprivileged user 101. `.dockerignore` riêng; Compose smoke dùng DNS service, chỉ publish 127.0.0.1:8080, có giới hạn RAM/CPU. Java Wrapper LF qua `.gitattributes` để checkout Windows/Linux dùng được.
8. Thêm 4 unit test ứng dụng và 6 Quarkus HTTP test, smoke runner container, đối chiếu OpenAPI runtime với spec P0-03. CI nền có job Java, legacy SQL, frontend và gateway + artifact report; chưa chạy hosted.

## Lỗi phát hiện và đã khắc phục

- Test đầu không khởi động do inject trực tiếp EntityManager của persistence unit inactive. Sửa thành `Instance<EntityManager>` và chỉ truy cập khi bật persistence; lần verify sau 10/10 đạt.
- `quarkus-junit5` bị relocate ở Quarkus mới; chuyển dependency sang `quarkus-junit` do BOM quản lý.
- Container build lần đầu wget tới Maven bị connection refused. Probe trong container sau đó truy cập được; chạy lại clean builder thành công bằng Wrapper đã khóa checksum. Không dùng host JAR để giả bằng chứng clean Linux build.
- Log còn warning metadata repo Flyway GitHub trả 401 nhưng dependency resolve qua Maven Central, và warning Mockito agent ở test. Không phải lỗi build/test; không cấu hình credential GitHub để chữa cảnh báo công khai này.

## Chưa làm/chưa kiểm chứng

- **Chưa có schema/profile database/roles/migration và test JPA với PostgreSQL thật cho service mới** — P0-05. Query JPA có code nhưng chưa được xác minh với dữ liệu thật; SQL test legacy không thay integration test JPA.
- Chưa có GET profile 200 từ DB thật. 503 và readiness DOWN hiện là trạng thái đúng của khung chưa cấu hình, không phải nghiệm thu PROFILE-01.
- Chưa JWT signature/issuer/audience/expiry, bootstrap, admin/blocked account hoặc private/write API — P0-06. Hiện những route này không tồn tại.
- Chưa nối FE vào API mới, sinh types/client, cache/auth reset/refresh/email confirmation — P0-07.
- Chưa full Compose FE/PostgreSQL/volume/migration job, image release/rollback độc lập có dữ liệu, DB disconnect/reconnect và durability — P0-08/10. Smoke chỉ kiểm dừng/chạy lại process upstream.
- Rate limit được cấu hình, chưa có test tải/rate-limit riêng. Chưa scan CVE toàn dependency Java/container; báo cáo npm 0 không áp dụng cho image/JAR.
- CI hosted và Auth thật chưa chạy. Không deploy, migrate hosted hoặc mở API public ngoài localhost.
