## Đã làm

- Thêm migration Flyway V1 tạo `profile_public`, `profile_private`, `profile_access`, constraint username/trạng thái, FK và timestamp. Không seed tài khoản/review giả vào database ứng dụng.
- Tách `profile_migration` (owner schema) và `profile_runtime` (quyền cột cần thiết). Runtime không sửa role/status, không DDL, không đọc lịch sử migration. Trigger owner tạo role MEMBER mặc định; metadata không tham gia cấp quyền.
- Thêm script init PostgreSQL phát triển bằng biến môi trường, không mật khẩu thật trong repo; thu hồi CONNECT mặc định. Đóng gói volume/Compose và kiểm thử init thực tế thuộc P0-08.
- Thêm command-mode migrator dành cho bước chạy có kiểm soát ở P0-08; API không tự migrate lúc startup. V1 được test bằng Flyway owner, ORM schema validate và runtime role riêng.
- Thêm Testcontainers PostgreSQL 17.12 theo BOM Quarkus; dữ liệu fixture chỉ nằm trong container test. Giữ test khung persistence-disabled riêng để kiểm tra 503.
- Phát hiện smoke gateway ghi `.tools` mà chưa tạo thư mục trên clone sạch; thêm tạo thư mục trước khi ghi. Job frontend/profile của CI commit trước đã đạt, gateway thất bại tại smoke; xác minh CI mới theo P0-09.
