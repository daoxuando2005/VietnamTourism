1. Xác định repo chính `VietnamTourism`, Git sạch trước sửa. Thư mục cha không phải Git repository; không sửa bản frontend khác ở thư mục `vietnam-tourism` ngang cấp.
2. Kiểm tra Git, Node/npm, JDK/javac, Maven, Docker/Compose và psql. Có Java 21.0.8; không có Maven/psql toàn cục. Docker CLI có nhưng Engine ban đầu tắt; đã khởi động Docker Desktop, xác nhận Engine 29.4.2 chạy Linux containers.
3. Khóa Node 24.22.3/npm 11.19.1, Java major 21, Maven 3.10.1 Wrapper 3.3.4 và Quarkus 3.40.1.2 LTS. Dùng Node portable local có kiểm SHA256 để khớp CI; không thay Node 26 toàn máy. Maven zip đối chiếu SHA512 chính thức, khóa SHA256 trong Wrapper.
4. Thêm `.env.example`, `.nvmrc`, `.npmrc`, engines/packageManager; Maven Enforcer kiểm Java/Maven, BOM/plugin cùng version. Khởi tạo workflow FE/Java và cấu hình kiểm thử.
5. Rà soát `.env` tracked: chỉ ghi nhận tên biến và phân loại public URL/anon key, không ghi giá trị vào báo cáo. `git rm --cached .env` giữ nguyên file local; thêm ignore config thật, build/cache/dump. Không viết lại lịch sử Git.
6. Frontend kiểm thiếu URL/key và chặn server/service-role key. Viết hướng dẫn [local/staging/production, Auth và Storage](../operations/DEVELOPMENT.md).
7. Clean install phát hiện 19 cảnh báo npm (11 moderate/8 high); chạy `npm audit fix --ignore-scripts` trong phạm vi semver đã khai báo, không force/nâng major; cập nhật lockfile rồi cài/build/lint lại.
