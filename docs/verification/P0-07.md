# Bản ghi P0-07 — Auth UI, session và API client

- Ngày: 22/11/2026, Asia/Saigon (bắt đầu 21/11).
- Yêu cầu: AUTH-01, PROFILE-01, SEC-01, TECH-01/03, UX-01/02.
- Trạng thái: **Hoàn thành triển khai FE và kiểm thử local**; email/provider thật còn cần nghiệm thu P0-10.

## Đã làm

- Đăng nhập, đăng ký chờ xác nhận, callback PKCE, quên/đặt lại mật khẩu, đăng xuất và hoàn tất username khi xung đột. Không dựng user giả khi đăng ký chưa có session.
- Biểu mẫu tiếng Việt, nhãn/ARIA/focus, validation giữ input, hỗ trợ password manager và bàn phím; kiểm tra bốn viewport 375/768/1024/1440.
- API client dùng Bearer từ SDK; một lần refresh dùng chung cho request đồng thời; 403 không refresh; refresh lỗi xóa phiên/cache. Chặn phản hồi A đến muộn sau chuyển sang B, chặn sự kiện refresh đến muộn trong lúc logout.
- TanStack Query theo subject, hủy/xóa cache và remount nội dung khi đổi danh tính. Return URL giữ query/hash, từ chối URL ngoài, protocol-relative và vòng lặp Auth.
- ProfileRepository đọc public/me qua gateway; bỏ đọc/ghi bảng profile Supabase trực tiếp. Admin UI dựa role từ API, máy chủ vẫn quyết định quyền.
- Sinh TypeScript types từ OpenAPI bằng Hey API (tương thích TypeScript 6), không chép tay DTO. Cập nhật dependency và override js-yaml 5.5.0; npm audit 0 vulnerability.
