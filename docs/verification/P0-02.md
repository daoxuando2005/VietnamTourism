- Trạng thái: **Chờ điều kiện để đóng toàn bộ nhiệm vụ**. Phần mã, migration và kiểm thử PostgreSQL local đã thực hiện; chưa áp dụng/xác minh trên Supabase hosted.

## Đã thực hiện

1. [Kiểm kê mã nguồn](../operations/LEGACY_INVENTORY.md): sáu bảng legacy, repository/query/join, ba trigger SECURITY DEFINER, Auth fallback, dữ liệu seed/mock và thiếu bằng chứng Storage hosted.
2. Thêm SQL [inventory chỉ đọc](../../supabase/inventory.sql) để lấy schema/policy/grants/function/trigger/count/Auth subject khi có owner test.
3. Tạo migration transaction không DROP TABLE/không xóa bản ghi: bật RLS, thay policy yếu, thu hồi table/column grants cũ; chủ sở hữu mới ghi review/favorite/profile/private; không sửa owner/counters/ID review qua API.
4. Tách liên hệ vào `profiles_private`, copy giữ nguyên dữ liệu, RLS riêng tư; giữ cột gốc dưới quyền owner để phục hồi. Khách/thành viên không đọc được private column gốc kể cả wildcard hoặc column grants cũ.
5. Giấu favorite feed cũ, ngừng phát favorite mới; giữ review trigger hoạt động. Khóa search_path của ba function, định danh bảng đầy đủ, thu hồi API EXECUTE, thêm fallback username trùng khi signup.
6. Cập nhật projection FE/auth/review/favorite/feed để tương thích quyền cột. Public profile không trả birth date/phone; owner đọc/ghi bảng private theo RLS.
7. Chuyển toàn bộ script reset cũ vào plain text `supabase/archive/legacy-demo.sql.txt`; entry point `schema.sql` chỉ còn guard, không còn lệnh reset ngay cả khi SQL client tiếp tục sau lỗi. Viết [runbook export/restore/apply/recovery](../operations/LEGACY_MIGRATION.md), thay hướng dẫn migration cũ có đường dẫn máy D: và yêu cầu chạy DROP.
8. Thêm runner tạo PostgreSQL 17.12 thật bằng container tạm/tmpfs, fixture auth.uid/roles tối thiểu và schema trích từ archive (không chạy reset/seed demo). Cleanup chỉ container test do runner tạo.
9. Thêm rollout flag private mặc định tắt, tránh query bảng mới khi hosted chưa migrate; không fallback ghi dữ liệu riêng vào bảng công khai. Chỉ bật khi DB/SDK đã xác minh, theo runbook.

## Kiểm tra và kết quả

`npm run test:legacy-db` → **Đạt**; [log đầy đủ](evidence/P0-02-legacy-db.txt).

| Nhóm | Đã xác minh |
| --- | --- |
| Khách | Đọc profile công khai; từ chối private column/wildcard/private table/favorite và ghi review |
| A | Tạo review/favorite, sửa profile, tạo/sửa private của mình; đọc đúng private của mình |
| A giả B | Từ chối ghi favorite/review/private giả chủ sở hữu; không chuyển owner review |
| B đối với A | Không đọc favorite A; UPDATE/DELETE review/favorite/profile/private của A không tác động bản ghi |
| Nâng quyền | Metadata admin không cấp ghi destination/counters/feed hoặc RPC trigger; không có admin nghiệp vụ thật ở legacy |
| Subject rỗng | Không đọc được favorite/private |
| Trigger | Username signup trùng có fallback; review insert/update/delete đồng bộ feed; favorite không phát hoạt động mới; favorite cũ bị giấu |
| Dữ liệu/migration | Chạy migration lại đạt, giữ private value và các dòng feed cũ |
| Backup/restore | pg_dump custom → restore database mới → row count/private data/column protection/RLS đạt |
| FE compatibility | TypeScript build và ESLint đạt sau đổi projection; chưa kiểm thử SDK/PostgREST thật |
