# Bản ghi P0-08 — Stack Docker và migration

- Ngày: 21/11/2026, Asia/Saigon.
- Yêu cầu: TECH-03/04, DATA-01/03, OPS-01, SEC-01.
- Trạng thái: **Hoàn thành local**. Stack dev dùng Auth hosted; kiểm thử tự động dùng stack test riêng với Auth fixture và PostgreSQL thật.

## Đã làm

- Dockerfile/image độc lập frontend, gateway, profile-service và target migrator. FE build từ source/npm ci; Java build bằng Wrapper/JDK 21, runtime chỉ có JRE. Không copy env local/dependencies vào context.
- Compose PostgreSQL 17.12 với volume bền vững, init role/database tách runtime/migration, DNS nội bộ. Chỉ frontend/gateway publish trên loopback; API/database không publish.
- Migrator chạy một lần, exit 0 trước API; API không mang migration password và không migrate tự động. Hibernate validate schema.
- FE/gateway UID 101, Java UID 10001; filesystem read-only và temp trong tmpfs. Sửa đủ thư mục temp Nginx khi chạy read-only.
- Gateway chuyển các route v1 tới service; DNS tự resolve lại sau khi tạo lại container. Script configure:local tạo mật khẩu ngẫu nhiên vào file ignored, giữ giá trị đã cấu hình.
- Stack test có namespace ngẫu nhiên; cleanup kiểm nhãn volume trước khi xóa riêng dữ liệu test. Stack dev/volume người dùng được giữ nguyên.

## Kiểm tra

- Build thành công cả bốn image; stack dev healthy tại frontend :3000 và gateway :8080, private API guest 401.
- `npm run test:stack`: 3 browser test dùng API/JWT/JPA/PostgreSQL thật đạt; operational checks tạo lại FE giữ ID API/DB, tạo lại API và DB vẫn còn hai hồ sơ test, mất DB trả readiness/API 503 rồi tự phục hồi.
- Chạy lại migrator giữ đúng một migration thành công; runtime non-root, không compiler/env trong /app, không có quyền tạo schema/cấp role/sửa quyền và không CONNECT postgres. Không publish API/DB.
- [Bằng chứng tổng hợp](evidence/P0-08-09-stack.txt); mã kiểm ở scripts/test-stack.mjs và tests/stack.
